# Declared deviations and unresolved disclosure limits

1. This rerun follows REL-default camera-centred geometry: `p_rel=p_camera@R_wc=p_world-C`. Real `t/C` is validated against W2C metadata and retained as provenance, but is deliberately excluded from ReD/EGVIA/LOA. The previous absolute-world run is not relabelled or reused.
2. Native ERP REL uses a radius-2 spherical support, while the local perspective square-support implementation uses radius 3. This run uses the perspective radius-3 estimator because the input is pinhole depth and records it in the manifest.
3. Pixel origin is not stated by the paper. The local calibrated perspective implementation explicitly uses 1-based pixels, so this run retains and tests that convention.
4. At the user's explicit request, execution uses eight physical GPUs while retaining the baseline's four logical data partitions, global batch 12, and 4,409 steps. Physical ranks use batches `[2,2,2,2,1,1,1,1]` and independent seeds `[0,1,2,3,4,5,6,7]`; paired valid-pixel loss normalization and a split logical sampler preserve the original four-rank sampler and loss algebra. Independent shard seeds avoid duplicated DropPath/Dropout and augmentation masks, but make the stochastic trajectory non-bitwise-equivalent to the historical four-rank HHA/RawDepth runs. The gate records this execution-topology deviation rather than claiming exact RNG equivalence.
5. The inherited baseline training loop has no validation pass and therefore no native validation-loss curve. Training loss remains in TensorBoard/logs. Any later offline validation-loss diagnostic is not used for checkpoint selection; no unavailable curve is fabricated.
6. Resume is supported only at a completed epoch boundary. The inherited `iteration` field is recorded but does not implement mid-epoch batch skipping.
7. Source REL provenance has no resolvable Git commit. Exact source paths and code hashes are retained instead.
8. `best.pth` equals `last.pth` (epoch 32), because epoch 32 is the only preregistered checkpoint eligible for the primary result. This avoids Area-5 checkpoint cherry-picking.
9. The initial four-GPU attempt and completed absolute-world eight-GPU run remain immutable historical evidence. This REL-default run regenerates all 70,496 cache images in a non-symlink run-local directory and resumes from neither historical checkpoint.
